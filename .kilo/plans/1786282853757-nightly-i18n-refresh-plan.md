# Plan: Nightly i18n Translation Refresh

## Context

Percussion CMS has 16 base i18n locales (`ar`, `bn`, `de`, `es`, `fr`, `he`, `hi`, `it`, `nl`, `pl`, `pt`, `ru`, `sv`, `te`, `tr`, `uk`) that need periodic machine-translation refreshes via `i18n_translate_direct.py`. The cache and TMX files are committed to source. A nightly cron job should translate one locale per day, create a PR with the changes.

## Files Modified

- `modules/perc-i18n/src/main/resources/i18n/{CmsUi.tmx,SystemResources.tmx,DeveloperUi.tmx}` — TMX with new `<tuv>` blocks
- `modules/perc-i18n/scripts/cache/i18n_translate.json` — shared translation cache (checked-in)

## Design Decisions

### 1. Locale scheduling
- `day_of_year % 16` selects the locale; deterministic rotation, no state file.
- Bases only — no regional variants in this job.

### 2. Cron
- `0 2 * * *` daily in user crontab.
- Shell wrapper sources `~/.bashrc` (fallback `~/.profile`) so `trans`, `gh`, `mvnw`, and `JAVA_HOME` are on PATH.

### 3. Scripts
- `scripts/nightly-i18n-refresh.sh` — shell entry point.
- `scripts/nightly_i18n_refresh.py` — Python wrapper (all logic).
- `scripts/test_nightly_i18n_refresh.py` — unit tests for pure logic.

### 4. CLI flags
- `--locale <code>` overrides day-of-year rotation (manual backfills).
- `--dry-run` skips all git ops; passes `--limit 5` to translation script (caps at 5 keys/phase).
- `--verbose` bumps log level to DEBUG.

### 5. Pre-flight checks (BEFORE any branch creation)
- `trans` on PATH.
- Working tree clean (`git status --porcelain` empty).
- On `main` branch.
- `gh auth status` succeeds.
- Any failure → exit with log message. No branch created.

### 6. Pipeline
1. Acquire `flock` on `tmp/nightly-i18n.lock` (gitignored).
2. Pre-flight checks.
3. `git fetch origin main`.
4. Check for open PR on `chore/nightly-i18n-refresh-<locale>` → skip if yes.
5. Delete branch if stale (>7 days, no PR).
6. `git checkout -b chore/nightly-i18n-refresh-<locale> origin/main` (or reuse existing branch).
7. `cd modules/perc-i18n && ../mvnw spotless:apply` (pre-clean).
8. `python3 modules/perc-i18n/scripts/i18n_translate_direct.py --target <locale>`.
9. `python3 modules/perc-i18n/scripts/i18n_translate_direct.py --target <locale> --fix-matching-en`.
10. `../mvnw spotless:apply` (post-clean).
11. Check TMX diff:
    - No TMX changes → delete branch, exit 0.
    - Has changes → stage TMX + cache, commit, push, create PR.

### 7. Commit / PR
- Commit message: `chore(i18n): Nightly i18n refresh for <locale>`
- Footer:
  ```
  > Automated via nightly-i18n-refresh cron
  > Co-Authored by Kilo using MiniMax-M2.7 with agent kilo.
  ```
- If translation errored mid-run, append `WARNING: Translation ended with error: <excerpt>` to message.
- PR title: same as commit.
- Labels: `operator:kilo`, `model:minimax`.
- PR body (auto-generated via `--body-file`):
  ```markdown
  ## Nightly i18n refresh for `<locale>`
  - Locale: `<locale>`
  - Date: YYYY-MM-DD
  - TUVs inserted: <count>
  - TUVs fixed (matching-en): <count>

  Auto-generated by `scripts/nightly_i18n_refresh.py`. See `~/logs/nightly-i18n-refresh.log` for the full run log.
  ```

### 8. Error handling
- **Pre-flight failure** → exit non-zero, no branch.
- **Translation partial + error** → commit what was done with WARNING in message, push, create PR (or delete branch if push fails).
- **Full failure / nothing to commit** → delete branch silently, exit 0.
- **Push failure** → retry 3× (10s, 30s, 60s backoff). If still fails, leave branch in place for next-night recovery.

### 9. Recovery (next night)
- Branch exists + open PR → skip.
- Branch exists + no PR + <7 days old → attempt push + create PR.
- Branch exists + no PR + ≥7 days old → delete, treat as fresh.

### 10. Concurrent run prevention
- `flock` on `tmp/nightly-i18n.lock` at script start. If held, exit immediately.
- Released via shell trap on script exit.

### 11. Logging
- Python `logging` to `~/logs/nightly-i18n-refresh.log` (matches crontab redirect).
- `RotatingFileHandler`: 10MB × 5 backups.
- INFO default, DEBUG with `--verbose`.

## Implementation Steps

### Step 1: Create `scripts/nightly_i18n_refresh.py`
Implements the pipeline in §6 with all the rules above. ~300 lines. Key modules:
- `argparse` for `--locale`, `--dry-run`, `--verbose`.
- `subprocess` for `git`, `gh`, `mvnw`, `i18n_translate_direct.py`.
- `logging.handlers.RotatingFileHandler` for log rotation.
- `fcntl.flock` on `tmp/nightly-i18n.lock`.

### Step 2: Create `scripts/nightly-i18n-refresh.sh`
```bash
#!/bin/bash
set -euo pipefail
source ~/.bashrc 2>/dev/null || source ~/.profile 2>/dev/null || true
cd "$(git rev-parse --show-toplevel)"
exec python3 scripts/nightly_i18n_refresh.py "$@"
```
`chmod +x` after creation.

### Step 3: Create `scripts/test_nightly_i18n_refresh.py`
Unit tests for pure logic (no live system calls):
- Locale rotation: `day_of_year % 16` → correct locale for known dates.
- `--locale` override skips rotation.
- `--dry-run` skips git operations.
- Lock file acquisition throws on contention.
- PR body generation includes locale, date, TUV counts.
- Branch staleness: 7-day threshold.
- Footer format includes Automated + Co-Authored lines.

### Step 4: Ensure labels exist
```bash
gh label create "operator:kilo" --force --color "d73a4a" --description "Work produced by Kilo Code agent"
gh label create "model:minimax" --force --color "1d76db" --description "Model: minimax"
```

### Step 5: Add to crontab
```bash
mkdir -p ~/logs
crontab -e
# Add:
0 2 * * * /home/nate/workspaces/intersoft-workspace/percussioncms/scripts/nightly-i18n-refresh.sh >> /home/nate/logs/nightly-i18n-refresh.log 2>&1
```

### Step 6: Update `scripts/README.md`
Add a section describing the workflow, locale rotation, and crontab setup.

## Validation

1. **Unit tests pass**: `python3 scripts/test_nightly_i18n_refresh.py` — all green.
2. **Pre-flight failure modes**:
   - Missing `trans` → clear error, no branch.
   - Dirty working tree → clear error, no branch.
   - Wrong branch → clear error, no branch.
   - Unauthenticated `gh` → clear error, no branch.
3. **Dry-run with override**: `python3 scripts/nightly_i18n_refresh.py --locale de --dry-run` — completes in <2 min, prints PR body preview, no git state.
4. **Lock contention**: Start two runs simultaneously → second exits immediately.
5. **First live run**: Use `--locale <one-locale>` to backfill, verify PR created, check TMX diff.
6. **Crontab fires**: Wait one night or temporarily set `*/2 * * * *` for a few minutes, verify PR appears.

## Risks & Mitigations

| Item | Mitigation |
|------|------------|
| Translate API rate limits | Script has 5× exponential backoff (2–60s). Partial commits preserve progress. |
| Network at 2am | Push retry 3×; branch-as-recovery-state for next night. |
| `trans` not installed | Pre-flight check with install hint. |
| `gh` auth expired | Pre-flight check with re-auth hint. |
| Cron minimal PATH | Shell sources `~/.bashrc`. |
| Dirty working tree | Pre-flight check; exits cleanly, no harm. |
| Long-running translation (>24h) | Next-night pre-flight sees dirty tree, exits; branch is finished next viable night. |
| Stale branch (no PR) | 7-day TTL; auto-deleted on next run. |
| Concurrent runs | `flock` lock file. |

## Out of Scope

- **Maven clean install / dist rebuild** — translation-only change.
- **Playwright tests** — translation is not a UI test surface.
- **Windows Task Scheduler** — Linux/macOS/WSL2 only (matches `trans` requirement).
- **Regional locale variants** — bases only for this job; can be added later if needed.
- **Cache pruning** — cache grows monotonically; out of scope for v1.
