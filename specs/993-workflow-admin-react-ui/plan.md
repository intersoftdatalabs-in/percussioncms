# Implementation Plan: Unified Workflow & Admin React UI

**Branch**: `993-workflow-admin-react-ui` | **Date**: 2026-07-20 | **Spec**: [spec.md](./spec.md)
**Input**: Feature specification from `specs/993-workflow-admin-react-ui/spec.md`

## Summary

Replace all legacy JSP/jQuery/Dojo-based Workflow Administration and Admin screens with a unified modern React TypeScript UI in `WebUI/`, following the established shell patterns of `ContentExplorerShell` and `PublishingShell`. Two new shells are introduced — `WorkflowAdminShell` (Workflow, Roles, Users, Categories) and `AdminShell` (Scheduled Tasks, System Tools) — mounted into updated JSP host pages and registered in `registry.ts`. All legacy JSP files are removed from the 8.2 distribution. No new backend REST endpoints are required; all REST APIs are already in place.

## Phases

- Add `WorkflowAdminShell` to `registry.ts`
- Add workflow API path constants to `api/paths.ts`
- Implement `WorkflowAdminShell` with section state machine (Workflow | Roles | Users | Categories)
- Implement `WorkflowSection` with workflow list, create/edit/delete workflow
- Implement `WorkflowEditor` with step list (`WorkflowStepList`) and step editor dialog
- Implement `WorkflowSiteAssign` dialog with async job progress polling

- Unit tests for all Phase 1 components
- E2E Playwright specs for US1 and US2
