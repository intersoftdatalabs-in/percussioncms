# perc-thumbnail

This lightweight module provides core infrastructure for generating image
thumbnails within the Percussion CMS platform. It is **not** a UI component; the
code is used by server‑side extensions (such as
`PSOThumbnailGenerator`) and by utility classes like `PSScreenCapture` to
produce or manage thumbnail images.

## What it does

* `PSScreenCapture` wraps an external command line tool to take a screen
  snapshot of a given URL and save it to a file. Configuration is flexible –
  the command is defined at runtime.
* `PSOThumbnailGenerator` (in `perc-toolkit`) uses the capture utility to
  produce thumbnails during workflow transformations.
* A default "empty thumbnail" image is bundled as a resource and can be
  copied by `PSScreenCapture.generateEmptyThumb()` when no source is
  available.

## Runtime configuration

At runtime the only required configuration is a `server.properties` file under
`<rxroot>/rxconfig/Server` containing the `screenshotCommandLine` property.
The value must be a command line that accepts two tokens:

```properties
screenshotCommandLine=<command> @@file@@ @@url@@
```

* `@@file@@` will be replaced with the destination path for the generated
  image.
* `@@url@@` will be replaced with the web address to capture.

For example, using the open-source `wkhtmltoimage` tool:

```bash
screenshotCommandLine=/usr/local/bin/wkhtmltoimage --width 300 --height 200 "@@url@@" "@@file@@"
```

If the command returns a non‑zero exit code the failure is logged and
processing continues without throwing an exception.  Thumbnails may also be
pre‑generated by other means; the utility classes are merely helpers.

## Developer notes

To build the module from source, run the standard Maven lifecycle from the
root of the workspace or from within the module directory:

```bash
# from project root:
./mvnw -pl modules/perc-thumbnail clean install

# or from inside modules/perc-thumbnail:
./../../mvnw clean install
```

Unit tests are written in JUnit 5 and require no additional setup – they create
a temporary `rxconfig/Server` directory and an innocuous
`server.properties` file when they run.  You can execute just the tests for
this module with:

```bash
./mvnw -pl modules/perc-thumbnail test
```

You may skip tests using `-DskipTests` if you're iterating on unrelated code.

Tests touch the file system as described above; they do **not** invoke any
real thumbnail binaries.  If you add new tests that require a live tool or
external process, mock the command string using the same token syntax shown
in the runtime configuration section.

Thanks for working on the thumbnail module!  Keep the code simple – most of
the heavy lifting is done outside of this project.
