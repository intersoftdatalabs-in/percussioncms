## Cross-platform path checklist

- Host install path is **literal `/opt/Percussion`** — both host and container use this exact path because the installer writes absolute paths to config files. User created `/opt/Percussion` on the host (owned by `nate:mkd-dev`). Symlink at `/opt/Percussion/JRE` (host-side) is portable — `ln -sfn`.
- Docker bind mount is `/opt/Percussion:/opt/Percussion` (same path on both sides) per user direction: "path in the docker container MUST match the path on the host system as install files set the path specifically".
- No OS-specific shell idiom. `set -euo pipefail`, portable `date +%Y%m%d-%H%M%S` for log filenames, `mktemp` for scratch files. Curl-based SQL curl is portable. No `${BASH_SOURCE[0]}`-only idioms (uses `cd "$(dirname "${BASH_SOURCE[0]}")/.."`).
