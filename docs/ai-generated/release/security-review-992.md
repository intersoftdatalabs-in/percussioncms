## T089 acceptance criteria

- ✅ No new server endpoint added by this feature.
- ✅ All client → server calls go through the existing fetch + CSRF wrapper.
- ✅ No `dangerouslySetInnerHTML`, no `eval`, no `new Function` in the modern CE TS/TSX.
- ✅ `safeNavigate` is the only `window.location` setter in the modern CE.
- ✅ `aclLockout.ts`, `canPasteInto`, `SEARCH_PERMISSION_DENIED`, `PERMISSION_DENIED` cover the user-visible permission gates; server-side AuthZ is the source of truth.
- 🟡 UAT acceptance pending: AuthZ negative test against the live CMS at the 8.2 GA candidate build (per `cutover-inventory.md` P-ACL sign-off row).
