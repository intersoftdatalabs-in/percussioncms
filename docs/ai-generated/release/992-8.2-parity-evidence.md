## 8. SC-012 release-decision packet (consumed by T090)

The release manager makes the SC-012 go/no-go based on this file plus the
per-component matrix. **The dependency-viewer / IA-relationship-views partial
state (1 of 6 dimensions populated, 5 rendering `—`)** is the only in-scope
matrix row that is not fully Done.

**Recommendation (Kilo)**:

Approve 8.2 GA **with** the 2 partial DependencyViewer / RelationshipsView
rows, on the following basis:

- All other P-Adv rows (clipboard copy/paste, SiteCopyWizard, SubfolderCopyWizard) are **Done** with end-to-end Vitest + Playwright.
- The remaining 5 dimensions depend on a `rest`-track enhancement that **is out of scope for the 992 train** (research/relationship-rest-gaps.md, T052-recorded gap, no invented fields).
- The client-side preview banner explicitly labels them as "Client-side preview" — operators are not misled into thinking the figure is authoritative.
- Functional parity per FR-029 (block 8.2 GA only "if any FR-029 parity clause fails") is preserved: **the paraphrase FR-029 picks out feature-completion, not deep-dimension completeness** in the dependency graph (which is a separate `rest`-owned feature).

If the release manager chooses the stricter interpretation (matrix preamble
"no post-8.2 deferral") then **block 8.2 GA** until the `rest` enhancement
ships; the modern CE surface is otherwise ready.
