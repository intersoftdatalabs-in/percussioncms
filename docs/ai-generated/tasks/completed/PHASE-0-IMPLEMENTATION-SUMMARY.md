# Phase 0 Implementation Summary

## Overview

Phase 0 of the WebUI Bundling Fix Plan has been successfully completed. The legacy JavaScript and CSS bundles that were previously generated by the minify-maven-plugin are now being built and packaged into the WAR file automatically as part of the Maven build pipeline.

## Files Changed/Created

### Created Files

1. **`WebUI/scripts/build-legacy-bundles.js`** (170 lines)
   - Node.js script that reads the minify JSON config files and concatenates source files into legacy bundles
   - Handles intermediate bundling (shared-common, shared-finder, etc.)
   - Creates final page-specific bundles (perc_dashboard, perc_webmgt, etc.)
   - Generates compatibility aliases (non-.min versions for PercProcessMonitor.jsp)
   - No external dependencies beyond Node.js built-in modules
2. **`WebUI/vite.legacy.config.ts`** (44 lines, not currently used)
   - Created as part of exploring Vite-based bundling (before switching to concatenation approach)
   - Kept for future reference or alternative approaches

### Modified Files

1. **`WebUI/package.json`**
   - Updated `build` script: Now runs `npm run build:modern && npm run build:legacy` (was just modern build)
   - Added `build:legacy` script: Calls the new Node.js bundle builder script
   - No new dependencies added
2. **`WebUI/pom.xml`**
   - Removed `<exclude>cssMin</exclude>` and `<exclude>jslibMin</exclude>` from the war plugin configuration (lines 579-580)
   - This allows the generated bundles to be included in the final WAR package
   - No other changes to the build pipeline
3. **`plans/WEBUI-BUNDLING-FIX-PLAN.md`**
   - Updated with implementation status showing Phase 0 is complete
   - Documented the specific changes made
   - Recorded test results

## Test Results

✅ **Build Pipeline**

- Maven build completes successfully: `mvn -f WebUI/pom.xml package -DskipTests`
- WAR file is generated with all bundles included
- Bundle sizes are reasonable (3-4 MB per page bundle)

✅ **File Verification**

- All 8 page bundles (.min and non-.min versions) generated
- All 8 CSS bundles (.min and non-.min versions) generated
- Files verified in WAR using `unzip -l`
- Paths match JSP expectations (e.g., `cm/jslibMin/perc_dashboard.packed.min.js`)

✅ **Compatibility**

- `.min` versions for regular JSP references
- Non-`.min` aliases for PercProcessMonitor.jsp absolute path references
- Both naming conventions now supported

## Known Limitations / Next Steps

1. **Delivery JS files** — `delivery/common/js/` files are missing from the working tree (exist in git but deleted locally). The bundle builder warns but continues successfully. These should be restored as part of a separate effort.

2. **No minification** — The bundles are concatenated but not minified. This differs from the original minify-maven-plugin which used Google Closure Compiler. Files are ~3-4MB each uncompressed, but gzip compression should reduce this significantly on the wire.

3. **No source maps** — Debug source maps are not generated. Could be added in future phases if needed.

4. **Phases 1-3 not yet implemented:**

   - Phase 1: Manage third-party libraries via npm (not attempted yet)
   - Phase 2: Address security issues (Handlebars CVE, etc.) (not attempted yet)
   - Phase 3: Modernization / React migration (not attempted yet)

## How to Build

```bash
# Standard Maven build (runs both modern React and legacy bundles)
./mvnw -f WebUI/pom.xml package -DskipTests

# Or just the bundle script for testing
cd WebUI && node scripts/build-legacy-bundles.js
```

## Configuration Files Referenced

The bundle builder reads these (pre-existing) JSON config files to determine what goes into each bundle:

- `WebUI/src/main/resources/minify/common-bundles.json` — Defines shared-common.js and related intermediates
- `WebUI/src/main/resources/minify/common-minuet-bundles.json` — Defines minuet variants
- `WebUI/src/main/resources/minify/static-bundles.json` — Defines the 8 final page-specific bundles
- `WebUI/src/main/resources/minify/common-ui-bundle.json` — Defines delivery-tier bundles

These files were originally created for the minify-maven-plugin and have been retained as the source of truth for bundle composition.
